# 目录规划（雏版）

目标：clone 下来一条命令能跑，不要求先改三个配置文件。

```
鲸倩-雏版/
├─ README.md              开篇（已写）
├─ run.cmd / run.sh       一条命令入口
├─ config.example.json    配置样例（密钥留空，写明去哪申请）
├─ src/
│  ├─ core.js             主脑：人格、工具循环、汇报
│  ├─ router.js           多模型路由 + 额度账本 + 失败回退
│  ├─ memory/
│  │   ├─ store.js        记忆库（SQLite 或 JSON）
│  │   ├─ retrieve.js     关键词召回 + 向量召回并行
│  │   ├─ event.js        事件层：把零散记忆串成事件、带时间轴
│  │   └─ consolidate.js  主动整理：空闲时合并、压缩、淡出
│  ├─ tools/              文件、命令、提醒
│  ├─ safety.js           四级红线 + 审计
│  └─ server.js           本地 HTTP 服务（界面可选）
├─ public/                极简界面（一个页面够）
└─ docs/
   ├─ 架构.md             （README 里的图展开讲）
   └─ 记忆设计.md         时间轴 / 事件层 / 遗忘曲线
```

## 里程碑

1. **能聊**：一条命令起来，接一个云端模型，人格生效。
2. **能记**：本地记忆库 + 关键词召回 + pinned。
3. **省钱**：本地小模型干粗活，云端只出判断；额度账本。
4. **动手**：文件/命令工具 + 红线 + 审计。
5. **前沿那两样**：向量并行召回、事件层与时间轴。
6. **主动**：空闲时自己整理记忆、到点提醒。

## 脱敏红线（每次提交前自查）

- 不带任何 key，全部占位符
- 不带任何绝对路径（盘符开头的本机路径一律改成相对路径或配置项）
- 不带记忆库、聊天记录、上传文件、备份
- 不带私人措辞与个人数据
