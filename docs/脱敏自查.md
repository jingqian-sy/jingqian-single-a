# 脱敏自查

> 打包前的自查记录。查的是「这个文件夹拿去公开，会不会漏出我的东西」。
> 结论：**通过**。下面写清查了什么、怎么处理的、还剩哪些风险。

## 一、查了什么

在仓库根目录，排除 `evals/.run/`（评测临时数据）、本地 `config.json` / `config.ci.json`，对仓库里会被提交的文件（约 118 个，运行时数据已被 .gitignore 排除）全量扫
（其中 23 份是评测产物：单A 的 `data/report.md` / `data/results.json` / `data/smoke.json` /
`data/ledger-summary.json` / `data/ledger/2026-11-01.json` + `data/archive/` 两版历史结果；
3A 的 `data-multi/report.md` / `data-multi/results.json` / `data-multi/restart-verify.json` /
`data-multi/logs/restart-verify.log`；2A 的同四份在 `data-2a/`，外加自适应判定的
`data-2a/adaptive-report.md` / `data-2a/adaptive-results.json` 和 `data-2a/archive/adaptive-v1/`
（判定与执行记录、run_id、score，没有真实聊天内容）——都只有评测题的回复、判定和状态迁移，
没有真实聊天记录）：

```bash
# 1) 密钥类：sk- 开头、长 Bearer、32 位十六进制
grep -RIn "sk-[A-Za-z0-9]{8,}\|Bearer [A-Za-z0-9._-]{12,}\|[0-9a-f]{32}" .

# 2) 绝对路径与私有痕迹
grep -RIn "D:\\\\\|C:\\\\\|用户目录名\|私有项目名\|私有端口" .

# 3) 数据文件：记忆库、聊天记录、上传、备份
find . -name "*.db" -o -name "*.jsonl" -o -name "*history*" -o -name "*memories*"
```

结果：**0 处密钥、0 处绝对路径**。原来那份描述私有实现细节的文档（端口、数据量、
私有文件名）已经改写成「能力取舍对照」，不带任何环境细节。

## 二、三类东西分别怎么处理

### 1. 密钥

- `config.example.json` 里所有 `key` 都是空字符串，写清去哪申请（platform.deepseek.com /
  open.bigmodel.cn / Ollama 本地）。
- 支持从环境变量读：配置里的 `"env": "DEEPSEEK_API_KEY"`，代码在 `src/server.js` 里
  优先取环境变量、其次取配置——**密钥可以完全不落盘**。
- 本地测试用的 `config.json` 已经被 `.gitignore` 忽略，里面只有一条本机 Ollama（无 key）。
- 代码里没有任何硬编码 key；日志里只记 provider 名和错误码，不打印请求头。

### 2. 绝对路径

- 所有路径都是「相对仓库根」算出来的：`path.join(__dirname, '..')`、
  配置里的 `data/workspace`，服务监听 `127.0.0.1`。
- 没有写死任何盘符或用户目录；自检输出里的工作目录是相对路径。
- `docs/目录规划.md` 里原来有一句举「盘符路径」的例子，已改写成描述性说法。

### 3. 私人数据

| 类别 | 处理 |
|---|---|
| 记忆库 | 仓库里没有任何 `memories.json`；跑起来才在 `data/memory/` 生成，且 `data/*` 被 gitignore |
| 聊天记录 | 没有历史会话文件；`data/sessions/` 同样是运行时生成、已被忽略 |
| 上传文件 / 备份 | 雏版没有上传和备份功能，目录里也没有 |
| 私有架构细节 | 原文档里的端口号、数据条数、私有文件名已删掉，改成能力对照 |
| 私人措辞 | 人格是通用的一份，题目是通用任务（记羽毛球、读笔记、算术），没有真实聊天内容 |

仓库里唯一带「本机事实」的是 `data/report.md`：OS 类型、Node 版本、模型名、耗时、
tokens、估算成本。这些是用来复现成绩的，不含个人信息；换台机器重跑一遍就会被覆盖。

## 四、还剩的风险（如实写）

1. `.gitignore` 防的是手滑，不是保险箱——真有人 `git add -f data/`，还是能提交进去。
   上线前建议再跑一遍本文件里的三条命令。
2. 服务默认只听 `127.0.0.1`，**没有登录鉴权**，别改成 `0.0.0.0` 挂公网。
3. `sandbox.mode: "none"` 时没有真隔离：红线是正则，拦得住手滑，拦不住精心构造的坏命令。
   要跑别人的代码请开 `process`/`docker`，或者自己套虚拟机。
4. 评测用的模型名会写进报表（`ollama-8b` 这类），这不算隐私，但如果你不想暴露用的哪家，
   把自己的 `config.json` 里的 provider 名改掉再跑。
