# 2.0 计划（基于 1.0）

> 一句话：2.0 是把 1.0 的承诺兑现——契约统一、红线确定、可换脑、可观测。
> 不是"多一堆新功能"，是让现在这套能被别人接、被自己管得住。

## 前提：1.0 还得能继续微调

行得通，但两条线要分开走，别混在一个工作区里改：

- **1.0 线**：`main` 分支，版本只走 `1.0.x`（修 bug、补文案、重打包）。每次发补丁打 tag（`v1.0.2`…）。
- **2.0 线**：从 `v1.0.1` 拉 `2.0-dev` 分支，大改都在这里。
- **合流**：1.0 上的修复用 `cherry-pick` 搬进 2.0，不要反向合并，避免 2.0 的新结构被拉回去。

理由：现在用户少，改内核代价最低；等有人装了 1.0 还在用，tools/memory 的契约就动不了了。

---

## M1 · 契约统一（地基，不做后面全卡）

**目标**：工具和记忆变成可挂接口，外部能注册、能读同一份。

- `tools` 契约：`{ name, description, params(schema), run(ctx, args) }`，内置工具和外部插件用同一套注册表。
- `memory` 契约：`search / remember / forget` 三个动作固定，外部实现（比如 DSH 的记忆库）能替换内置那份。
- 插件从"四权限"升级成"能力 + 契约"：`tool / route / ui / memory` 只是声明，落到契约上。

**验收**：
- 写一个只有 20 行的外部工具插件，不碰 `src/` 就能挂上并被模型调用。
- 把内置记忆换成假的（内存实现），`evals/memory-test` 全过。

**风险**：1.0 的工具是写死的，改契约会牵动 core.js 一大片。建议先加一层适配，别一次性重写。

---

## M2 · 红线执行层（确定性，不靠提示词）

**目标**：dangerous 操作在执行前被拦，不是在提示里劝。

- 分级：P0 直接拒（格式化、删系统盘、改注册表启动项）、P1 要确认、P2 记录放行。
- **判定用确定性规则**（路径白黑名单 + 命令正则 + 工具名），不用小模型——这地方漏一次就是事故。
- 每次拦截写 `data/redline.log`：谁、什么命令、为什么拦、结果。
- 和沙箱打通：拦下来的不进沙箱。

**验收**：
- `evals/redline-test.js`：30 条恶意/危险命令，P0 100% 拦、P1 100% 要确认、正常命令 0 误杀。
- 审计日志能还原"这条为什么被拦"。

**风险**：误杀会让人烦。宁可 P1 多问一句，也别 P0 乱拒。

---

## M3 · 换脑向导（用户能感知的第一步）

**目标**：一行配置接进现有 AI，或者换模型时人格记忆都跟着走。

- 设置里两个入口：「接入」（把她挂进你正在用的 AI，生成 MCP 配置片段）和「换脑」（换模型/换家）。
- 自动检测本机 DSH、生成配置、提示重启；检测不到就给手填模板。
- 换模型时：人格、记忆、历史、插件不动，只有推理那层换掉。

**验收**：
- 从零装了 DSH 的机器上，向导走完能直接调 `jingqian_*` 四个工具。
- 换模型前后，同一句"我爱喝什么"答案一致。

**风险**：DSH 版本差异大，配置格式会变。做成"模板 + 校验"，别硬编码。

---

## M4 · 可观测：能力档案 + 选路理由

**目标**：为什么选这家、这个工具干了什么，界面上看得见。

- 每家模型一份能力档案：能不能挂工具、上下文多大、大概多快多贵（可在设置里手改）。
- 每次选路写一行理由：`选了 X，因为能挂工具 + 在预算内 + 上次失败冷却已过`。
- 工具调用可回放：入参、出参、耗时、是否被红线拦。

**验收**：
- 窗口底部能点开"这次为什么用它"，看到理由链。
- 同一条消息，故意把首选模型设成不支持工具，能看见它自动降级并说明。

**风险**：日志一多就没人看。默认只留最近 200 条，可导出。

---

## M5 · 上下文与流水线（锦上添花，提前不定死）

**目标**：按 token 裁窗口；小模型干它擅长的活。

- 上下文按 token 算（不同模型的 tokenizer 有差异，先按字符估算 + 可调系数）。
- 小模型流水线（只做三道）：
  1. **值不值得记**（二分类，标签小、输出短）
  2. **相关性粗排**（1000 段挑 50 段递给大模型）
  3. **短摘要**（可接受丢细节，原文一定保留）
- 插件声明能力需求（`requires: tools | browser | office`），切到挂不了工具的模型时自动标灰。

**明确不做**：小模型抽结构化 JSON、小模型"修" JSON、小模型判安全。这三件事确定性代码更靠谱。

**验收**：
- 0.8B 做二分类，100 条标注样本准确率 ≥ 90%，不确定的走兜底。
- 粗排把 10 万字缩到 2 万，大模型总结质量不掉档。

---

## 硬边界（2.0 也不碰）

1. 不打包、不自动部署第三方网关（SnowLuma 的 EULA 明确不许并入安装包）。
2. 不做多账号、不做风控绕过、不自动加好友。
3. 不把 7889 暴露公网，服务始终只监听本机。
4. 群聊能力保持"必须 @ 或点名才回"，不刷屏。
