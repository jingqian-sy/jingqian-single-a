# 从私有实现到开源雏版：哪些留了、哪些没带

> 这个仓库是**单A 开源雏版**。下面只讲能力上的取舍，不写私有版本机的任何路径、
> 端口、数据量——那些不该出现在公开包里。

## 留下的（这几处是这套东西真正的价值）

| 能力 | 开源雏版落在哪 |
|---|---|
| 混合召回（关键词 + 向量，两路并行） | `src/memory/retrieve.js` |
| 遗忘曲线 + 重要性分层 + pinned | `src/memory/retrieve.js`、`src/memory/store.js` |
| 事件层与时间轴（零散话串成事） | `src/memory/event.js` |
| 主动整理（合并重复、压摘要） | `src/memory/consolidate.js` |
| 多模型路由 + 免费额度优先 + 失败回退 | `src/router.js` |
| 按天按提供方的额度账本 | `src/router.js`（`data/ledger/`） |
| 工具循环 + 预算护栏 | `src/core.js` |
| 四级红线 + 审计日志 | `src/safety.js` |
| 可开关的沙盒（三档） | `src/sandbox.js` |
| 本地 HTTP 服务 + 极简页面 | `src/server.js`、`public/` |

## 没带的（私有版有，雏版故意不做）

- **C# 桌面壳**：雏版用浏览器页面，一条命令起来就够，不要求先编译。
- **QQ / 手机桥接**：属于外部通道，跟核心能力无关，接进来还得处理鉴权。
- **上传、看图、语音**：都要额外模型或组件，会把「clone 下来能跑」这条破掉。
- **备份 / 还原演练 / 自更新 / 看护进程**：运维那一套，个人用雏版用不上；
  雏版的稳定性只靠「每步落盘 + 启动重建」，够用，但不吹。
- **插件系统、任务队列、子智能体**：单A 模板刻意保持「一个主脑、单任务串行」，
  多体编排留给 3A 模板。
- **知识图谱**：私有版也还没做，这边不假装有（事件层的实体只是字符串匹配，不是图谱）。

## 一句话

雏版不是把私有版删减打包，而是**按同一套协议另写了一份实现**：
协议共用（记忆字段、事件、工具契约、红线级别、账本、评测集），实现不共用。
这样两个模板才能各自演进、又被同一批任务公平比较。
