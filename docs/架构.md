# 架构（完工形态）

> 配图：2026-11-01 那张「鲸倩 · 完工架构」。这里是同一份内容的文字版。

## 入口
桌面窗口（鲸倩桌面版）· 手机网页（局域网 / 组网）· QQ 桥接

## 主脑
人格 · 判断 · 汇报 · 派活。粗活外包，值钱的判断自己做。

## 四个专用模块

### 1. 记忆系统
- 关键词召回
- 向量召回（2048 维）
- 知识图谱：实体 · 关系
- 图谱 + 向量混合召回
- 事件层 · 时间轴
- 遗忘曲线 · pinned
- 主动整理（空闲复盘）

### 2. 模型路由
- 云端多家（OpenAI 兼容接口）
- 本地 8B / 14B
- 免费额度优先
- 按难度与环境选路
- 额度账本 · 按天记账
- 失败自动回退 + 日志
- 缓存友好前缀

### 3. 工具与红线
- 文件 · 命令 · 提醒
- 四级红线 P0-P3
- 审计日志（可按级别筛）
- 看图（视觉模型）
- 语音输入
- 发图 · 发文件
- 禁止不可逆操作

### 4. 任务与子体
- 任务状态机：待批准 → 排队 → 执行 → 汇总 → 推回对话
- 单任务串行
- 超时熔断 · 重试 · 撤回
- 子智能体（六步上限）
- 不套娃 · 只交结论

## 底座
- 记忆库：SQLite，可备份可还原
- 备份 + 还原演练：核对 + 抽样还原
- 自更新：校验 · 备份 · 可回滚
- 搬家 + 自检看护：整个文件夹带走

## 规矩
改动先备份 · 服务有看护 · 每周自检与还原演练 · 所有动作留日志。

## 省钱路线
粗活给本地 8B/14B，值钱的判断给云端，免费额度先用。

- 多 Agent 编排（只做演示用）
