# 电脑上的软件：能接哪些、怎么接

扫了 157 个已安装项。分三档：**能写插件／能写桥／只能外部自动化**。
安全软件和反作弊明确不碰（火绒、迈克菲、AntiCheatExpert 这类）。

## 一档：有官方扩展点，能写插件（最稳）

| 软件 | 扩展方式 | 能干什么 | 工作量 |
|---|---|---|---|
| VS Code | 官方 Extension API | 读写编辑器、命令面板、状态栏、调用终端 | 1–2 天 |
| Microsoft Edge | 浏览器扩展（MV3） | 抓页面、加侧边栏、调本地服务 | 1 天 |
| DSH | MCP / 插件 | 已经做了（jingqian_* 四个工具） | 已完成 |
| Wallpaper Engine | 官方 SDK / 壁纸工程 | 换壁纸、联动状态 | 半天 |

## 二档：有 API / CLI / COM，能写桥（次稳）

| 软件 | 接口 | 能干什么 | 注意 |
|---|---|---|---|
| Microsoft 365（Word/Excel/PPT/OneNote） | COM 自动化 | 生成文档、填表、批量改、导出 PDF | 要开着 Office；杀毒可能拦 |
| Ollama | HTTP API（11434） | 已经在用（本地模型） | 已完成 |
| Steam | SteamCMD / 本地配置 | 查库、下载、启动游戏 | 别碰账号密码 |
| 剪映专业版 | 草稿工程文件（JSON） | 批量生成草稿、改字幕、套模板 | 非官方格式，版本变了要跟 |
| QQ / 微信 | 走现成桥接（OneBot 那类） | 收发消息、推送提醒 | 有风控；别用主号 |
| 网易云 / 哔哩哔哩 / 夸克 / 豆包 | 无官方接口，多为网页壳 | 只能走浏览器自动化（CDP） | 页面改版就废 |

## 三档：没有扩展点，只能外部自动化

- 游戏类：原神、崩铁、三角洲、饥荒、逆战、和平精英模拟器 → 键鼠自动化能做，但**有反作弊，做的收益低、风险高，不建议**
- 硬件/驱动类：ASUS 全家桶、NVIDIA App、Logitech G HUB、天选姬 → 读状态可以（WMI/驱动接口），控制有限
- 安全类：火绒、迈克菲、AntiCheatExpert → **不碰**
- 其他：UU 加速器、向日葵、腾讯会议、腾讯视频、抖音、YY9 等 → 只能快捷键 + 找窗口

## 我建议的顺序

1. **VS Code 扩展**（最值）：把她接进编辑器，能读当前文件、按指令改代码、跑终端。
2. **Office COM 桥**：做表格/文档的批量活，正好对口你的报价单、排期表。
3. **剪映草稿生成**：批量出视频草稿，做宣传片快。
4. **QQ/微信**：只做推送通道，不做主入口。

前三个我能直接开工，每个都是「写代码 + 本地验证」，不动系统设置。
