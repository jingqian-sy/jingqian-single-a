# 鲸倩 1.0：解压就能用、能带走的电脑里的她

一个住在你自己电脑里的中文助手：会记事、会算账、会动手，但手上有一条红线。Windows 绿色版，解压即用，数据跟着文件夹走。

## 怎么用（三步）

1. **解压**：把 `jingqian-portable-1.0.0.zip` 解压到任意文件夹（U 盘也行）
2. **启动**：双击 `启动鲸倩.cmd`（想放桌面就再双击 `创建桌面快捷方式.cmd`）
3. **接模型**：第一次打开会让你配模型，二选一——
   - **云端**：设置 → 一键配模型 → 选一家 → 粘 key（智谱 GLM-4-Flash 有免费额度）
   - **本地**：先装 Ollama，软件会自动认出来，完全免费、不用 key

然后直接说话就行。要它干活就直说（「在工作目录建个 a.txt，写 hello」）；它调用工具时，消息区会留一条灰色小条。

数据都在文件夹里：`data\`（记忆、会话、账本）和 `config.json`（含 key）。整个文件夹搬走就跟着走；更新时覆盖程序，**别覆盖这两个**。

## 全部功能

**聊天与窗口**
- 独立窗口，不跳浏览器；气泡可选中/复制，右键复制单条或全部
- 文件、图片直接拖进窗口；图片会交给支持视觉的模型看
- 回复能朗读（系统 TTS，不联网）；输入框旁「说话」可用系统中文语音识别
- 会话列表：翻历史、搜关键词、切回去接着聊、删会话；切会话保留没发完的草稿
- 长会话：滚到顶自动加载更早记录，往上翻时新消息不抢滚动，End 回到底部

**模型与花费**
- 多家云端 + 本机 Ollama；一键配模型（选一家、粘 key、自动问模型列表、测通再选）
- 工具栏热切换：自动（先免费/省）/ 质量优先（先云端）/ 指定某一家
- 今日账单：常驻金额 + 按家明细 + 只打水位线的重置；可设每天花费上限
- 选路有护栏：固定模式不升级、会话内不换人、失败家冷却 60 秒、空回复云端补一次、全挂时说人话

**对话 / 工作模式**
- 对话：不挂工具，只聊天，免费模型也能用；认出是干活的话会问你要不要切工作模式，点「是」就切
- 工作：挂全套工具，只让能动手的模型接活；固定到带不了工具的家会直接说清楚，不偷偷换
- 窗口、QQ、MCP 三个入口各存一份模式，互不影响，热生效

**记忆**
- 自动记：约定、偏好、重要日子会自己记；也能手动搜、删
- 分层：core / relation / cue，重要的常驻，琐事问到才想起来
- 人物表：认人、别名、归属；群聊里谁说的记在谁名下，不串人
- 同一件事换个说法会去重；说「不对，我其实……」会顶掉旧说法
- 间隔复习：常用的记得更牢，闲置的自然淡出；每天自动快照
- 上下文按字数档位（省 4000 / 标准 8000 / 大 16000 / 超大 32000），原文不删，摘要只是给模型的压缩视图，旧细节还能翻会话/搜历史找回

**工具与红线**
- 读写文件、列目录、跑白名单命令、联网抓网页（拒内网）、搜历史会话
- 触手：看屏幕、点按打字、操作受控浏览器（可关）
- 子智能体：派一个独立分身去干活，只回结论
- 红线：P0 直接拒、P1/P2 要你确认；删系统目录这类活会先看再拒，并给替代方案
- 命令白名单 + 沙盒（none / process / docker 可选）

**插件**
- 插件用 `plugin.json` 声明权限：工具 / 本机接口 / 界面按钮 / 记忆
- 插件页支持装、启停、卸载、运行插件按钮；示例见 `plugins-example/memo`
- 这一版是「可信插件」：插件和服务同进程、同权限，只装你看过源码的

**QQ（可选，默认关）**
- 支持 OneBot HTTP 推送和 WS 直连（SnowLuma / NapCat / LLOneBot）
- 一键找网关、白名单私聊号、群白名单、群里必须 @ 或点名才回
- 群聊带说话人，群友的事记在群友名下；有「先只记录不回复」的验证开关
- 说明：群聊只用模拟环境验证过，真实群请自备网关自行验证

**进阶**
- 内置 MCP 客户端（stdio，默认关，只认本机绝对路径命令），工具以 `mcp__服务__工具` 进工具表
- 自检：`鲸倩.exe --verify`；截图/演示：`--shots`、`--send-shot`
- 评测：质量对照 25 题、CI 32 步（含记忆、人称、群聊、模式、上下文、插件、QQ）

## 本机实测（2026-11-03，Windows，单机小样本）

- **CI**：32 步全绿，56 秒；不联网、不花 token
- **质量对照**：25 题 25/25（1.17 版实测；之后没重跑整套，改动主要在校验项上）
- **真机记忆对照**：临时库种 5 条事实问 3 题（车位 / 生日 / 没提过的车牌）
  - DeepSeek：16/16 符合预期
  - qwen3-8b（本机）：16/16 符合预期，含 8000 字人格
- **速度**：DeepSeek 单问约 0.5~1.2 秒；qwen3-8b 约 2.5~8.7 秒
- **长人格成本**：8000 字人格单轮约 6.4k tokens；短人格约 0.5k
- **离线用例**：人称 23 条、群聊 11 条、上下文 6 条、模式 24 条、报错 19 条、插件 15 条、QQ 适配若干，全过
- **模型列表**：智谱 12 个、DeepSeek 2 个、火山 138 个、本机 Ollama 4 个
- **便携版**：拷到带中文和空格的路径，用它自带的 node 起服务成功

> 声明：单机、小样本、临时库，不是官方跑分；不同网络、不同 key、不同机器会有差别。欢迎把你的数据贴到 Issue，我汇总进 `docs/实测数据.md`，标清环境和模型，不写成官方结论。

## 已知限制

- 只支持 Windows；需要 .NET Framework（Win10/11 自带）
- 不联网就没有云端模型，得用本机 Ollama
- `config.json` 里有 key 明文，别放公用电脑/U 盘
- 插件是可信插件模式，没有隔离
- DSH 接入、开发者模式等进阶能力在 2.0，不在这一版

## 遇到问题 / 想反馈

开 GitHub Issue 就行，标题前加 `[BUG]` 或 `[数据]`。为了让问题能定位，麻烦带上：

- Windows 版本、是不是绿色版
- 用的哪家模型（提供方 + 模型名）、云端还是本机 Ollama
- 你怎么操作的、期望是什么、实际发生了什么
- 能复现的话，附上 `data\` 里对应的会话截图或日志（**把 key 和私人内容打码**）

**不同模型跑出来的数据也欢迎贴**：同一件事用不同模型，耗时、花费、成不成、答得对不对，都可以发。我会整理成 `docs/实测数据.md`，标清楚「谁测的、什么环境、什么模型」，不吹成官方结论。这类数据对别人选模型很有用。

## 想加什么功能

也开 Issue，标题加 `[功能]`，说清楚**你想用它干什么**（场景比功能名有用）。会按三个原则取舍：

- **默认安全**：会碰系统、装东西、给模型放权的，默认关，想要再开
- **小白优先**：主路径保持「解压 → 启动 → 填模型 → 聊天」，进阶功能不塞进第一眼
- **进阶放 2.0**：DSH 接入、开发者模式、外部工具这些，统一进 2.0

不承诺都做，但每条都会看；被采纳的会写进 CHANGELOG 并注明是谁提的。

## 2.0 预告（完整）

2.0 的关键词是**一个核、两个前端**：核心是本机服务，窗口只是其中一个前端。

1. **DSH 接入向导**（设置里，两个选项）
   - 接入（工具）：DSH 里能问她、搜/写她的记忆、看状态
   - 换脑：DSH 的聊天界面直接由她回答，用她的人格和记忆
2. **换脑的底座**
   - 软件核心提供 OpenAI 兼容接口
   - 内核能接收外部工具清单并回 tool_calls，把 DSH 的工具接给她用
3. **红线执行层**
   - 工具执行前先过 `safety_check`，不只靠提示词
   - 不管是她自己的工具还是外部工具，都走同一道闸
4. **开发者模式**（默认关，红字警告）
   - 放开安装目录读写、允许她自己安装/启用插件
   - 给愿意承担风险的人用，不默认对小白开放
5. **插件开发助手**
   - 你说需求，她写插件草稿
   - 界面上给「安装并启用」，必须你点头，模型不能自己装
6. **上下文预算升级**
   - 按 token 而不是字数裁
   - 人格按需注入，不每轮都带
   - 工具 schema 按场景折叠
7. **内核契约统一**
   - tools / memory 契约打通，1A、2A、3A 共用同一套
   - 多角色（3A）继续做对照评估，不承诺默认可用
8. **可选：记忆向量检索**
   - 现在 embedding 默认关；2.0 评估默认开启，让「换个说法也能想起来」更稳

2.0 不会改变 1.0 的用法：还是解压即用，进阶能力默认关，想要再开。
