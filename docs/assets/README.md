# 截图放这里

README 顶部的截图占位，指的就是这个目录。

自己截一张：

1. `node src/server.js`，浏览器打开 `http://127.0.0.1:7889`；
2. 随便聊两句（让它记件事、再问回来），把输入框和顶部状态那行一起截进去；
3. 存成 `screenshot.png`（宽 1200 左右，PNG，建议 ≤ 300 KB）；
4. 把 README 里那行注释掉的图片引用打开：

   ```markdown
   ![鲸倩界面](docs/assets/screenshot.png)
   ```

> 别把带真实聊天内容、真实 key 的截图传上来。
