# 插件模组：自己给自己的鲸倩加功能

一句话：一个插件就是一个目录，里面一个 `plugin.json` 清单 + 一个 `index.js` 入口。
装进去、启用，她就能用插件给你的工具；停用或卸载就干净退出，不用改核心代码、不用重启服务。

## 一、插件长什么样

```
data/plugins/memo/
  plugin.json
  index.js
  data/          ← 插件自己的数据目录（运行时自动建，随便用）
```

`plugin.json`：

```json
{
  "name": "memo",
  "title": "随手记",
  "version": "1.0.0",
  "description": "给模型加两个便签工具",
  "main": "index.js",
  "permissions": ["tool", "route", "ui"],
  "ui": { "label": "看看便签" }
}
```

- `name` 只能是小写字母、数字、`-`、`_`，2~32 位，并且**必须和目录名一致**；
- `main` 不许指到插件目录外面；
- `permissions` 只能写下面五个，没声明的能力调了会直接报错。

| 权限 | 能干什么 |
| --- | --- |
| `tool` | 注册工具，模型可以调用 |
| `route` | 注册本机接口 `/api/plugin/<名字>/<路径>` |
| `ui` | 在「插件」页给一个按钮，点了跑 `ui.run()` |
| `memory` | 读写主程序那份记忆库 |
| `proactive` | 让她自己开口说话、给她注册定时器 |

`index.js`：

```js
module.exports = function (ctx) {
  ctx.log('我上工了');                 // 写 data/plugins.log

  ctx.registerTool({ name: 'memo_add', description: '记一条' },
    { type: 'object', properties: { text: { type: 'string' } }, required: ['text'] },
    function (args) { return '记了：' + args.text; });

  ctx.registerRoute('GET', 'stats', function () { return { ok: 1 }; });

  ctx.ui = { label: '看看便签', run: function () { return '空的'; } };
};
```

`ctx` 上只有这几样：`name`、`title`、`version`、`dataDir`、`log()`、`registerTool()`、
`registerRoute()`、`memory.{add,search}`、`proactive.{say,idleMinutes}`、`tick()`、`ui`。
别的一个都拿不到。

`proactive` 是「让她自己开口」：`ctx.proactive.say({ sessionId, idleMinutes, target })`
会用同一个人格和记忆生成一句话，写进会话历史（桌面窗口能看到）；`target: 'qq'` 时
还会从网关照发一份出去。`ctx.proactive.idleMinutes('desktop')` 告诉你这个会话
最后动静到现在隔了几分钟。`ctx.tick(fn, ms)` 注册定时器，重载插件时会被自动清掉，
别自己裸写 `setInterval`。

## 二、怎么装

1. 打开软件版 → 工具栏「插件」→「安装…」→ 选插件目录（有 `plugin.json` 的那个）；
2. 列表里选中它 →「启用/停用」；
3. 想验证插件真跑起来了：如果它有界面按钮，点「运行插件按钮」；
   如果是工具类插件，直接在聊天里让她用（比如「记到便签：明天交房租」）。

启用状态写在 `config.json` 的 `plugins.enabled` 里，重启之后还在。

命令行等价：

```
GET  /api/plugins                       列出已装插件、启用状态、加载错误
POST /api/plugins/install   {path}      从本地目录安装（复制进 data/plugins）
POST /api/plugins/enable    {name}      启用（立即加载，不重启）
POST /api/plugins/disable   {name}      停用（工具一起下线）
POST /api/plugins/uninstall {name}      卸载（目录一起删）
POST /api/plugins/ui        {name}      跑插件的界面按钮
GET  /api/plugin/<name>/<path>          插件自己注册的接口
```

这些接口只给本机调用（同中控台）。

## 三、内置插件：自由时间

随包带的一个插件，不用装——第一次启动会自动复制进 `data/plugins/free-time` 并开启。
它干的事：**你多久没说话，她就自己想找你聊一句**，桌面窗口里会多一条她的消息；
接了 QQ 而且最近有人在 QQ 上找过她，就顺手发到 QQ。

默认规矩（`data/plugins/free-time/data/settings.json`，改完一分钟内生效，不用重启）：

| 字段 | 默认 | 意思 |
| --- | --- | --- |
| `enabled` | `true` | 总开关 |
| `idleMinutes` | `30` | 多久没动静才轮到她开口，最少 5 |
| `maxPerDay` | `5` | 一天最多几次 |
| `quietStart` / `quietEnd` | `23:30` / `08:00` | 这个时段不打扰，跨零点也认 |
| `targets` | `["desktop","qq"]` | 往哪儿说 |

说话内容不是插件定的，是主程序用同一套人格和记忆现生成的——所以你说过的事她记得。
不想让她主动开口，把 `enabled` 改成 `false`，或者在插件页停用。

看它现在什么状态：`GET /api/plugin/free-time/status`，会返回今天说了几次、上次说了什么。

## 四、示例插件

`plugins-example/memo/` 是最小的完整例子：两个工具（`memo_add` / `memo_list`）、
一个接口（`/api/plugin/memo/stats`）、一个界面按钮。装它的办法：

软件版 → 插件 → 安装… → 选 `plugins-example\memo` → 启用。

界面长这样：`docs/assets/软件版-插件.png`（列表里能看到名字、版本、状态、权限、说明）。

## 五、说清楚风险（重要）

这一版是**可信插件**模式：插件和服务跑在同一个进程里，权限也一样。
也就是说，一个写坏的插件能把服务搞挂，理论上也能读本机文件。

- 只装你自己看过、信得过的插件；
- 装之前扫一眼 `index.js`，看它有没有乱读文件、乱发网络请求；
- 卸载等于删目录，插件自己的数据也一起没，重要东西先备份。

下一步才是真隔离（worker 线程 + 权限代理 + 网络白名单），这版先不画这个饼。

## 六、测过什么

`node evals/plugins-test.js`，15 条断言，进 CI 第 23 步：

- 从本地目录装、装完默认不启用；
- 启用后工具立刻可用，插件工具真能跑（写进去再读回来）；
- 插件自己的接口、界面按钮都能通；
- 没声明权限就调 `registerTool` → 插件加载失败，但主服务照常；
- 停用、卸载都干净，状态写回 `config.json`。
